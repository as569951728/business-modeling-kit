# v0.2.1 资料整理与访谈准备入口复查

日期：2026-11-15。本次是通用工具包说明完善，未开展任何客户材料整理。

## 用户需要与修订

用户说明自己不熟悉建立业务模型需要整理什么，希望直接交手头材料，由 AI 按工具包处理；本轮并非指定某个客户项目。

- 以前入口优先“生成实施方案”，04 的“先放好／先填好”容易让用户以为要先懂分类或备齐材料。现明确用户交原件，AI 按知识和 C01–C12 盘点。
- 在 05 写明完整输入、动作、输出和完成标准，README、START-HERE、AGENTS、04、08 连到同一方法，不重复增加一套表。
- 交付现状摘要、资料与缺口记录和两页现场访谈单；已有记录直接复用，详细索引不挤进现场版。
- 原件保留，分类允许一份支持多项；缺口区分未提供、未读完、解释不足、不同说法和不适用。内部技术判断转成客户能回答的问法。
- 讨论通用用法时不追问客户或启动项目；准备访谈不自动进入模型采用、运行或验收。

## 说明一致性走查

| 情境 | 文档规定的处理 |
| --- | --- |
| 用户不懂术语，交来混合材料 | AI 分类和填记录，不把分类作业退给用户 |
| 目标尚模糊 | 归纳候选方向及依据，保留待定，不自行承诺范围 |
| 材料重复、局部不可读 | 索引去重但保留原件与版本；记录实际阅读覆盖 |
| 只有个人说法，缺正式依据 | 区分信息性质，列待核，不补造制度或授权 |
| 只要准备访谈 | 交准备成果，仅更新有实际依据的盘点状态 |
| 用户只讨论通用方法 | 完善方法，不索要具体项目或创建客户工程 |

上表是本次说明走查，未作为独立新 AI 的行为测试结果。
