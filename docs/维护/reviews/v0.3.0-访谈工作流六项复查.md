# v0.3.0：实际使用后的六项改进

日期：2026-11-15。依据用户对 v0.2.1 的六项具体反馈，并阅读其可见的资料摘要、缺口台账和访谈准备成果；本包只收录通用改进，不复制该练习的事实或答案，也未改动其项目文件。

## 逐项对应

| 用户反馈 | v0.3.0 的可复用产物 | 具体解决什么 |
| --- | --- | --- |
| 资料盘点无专用模板 | [资料盘点](../../../templates/资料盘点.md) | 固定来源、版本、阅读覆盖、信息性质、支持认识与缺口的关联 |
| 问题缺少排序方法 | [09 第 2 节](../../访谈/09-访谈准备与交接.md)、[访谈准备底稿](../../../templates/访谈准备.md) | 先过滤，再按依赖、影响和角色选择；先问、复用、条件追问、延期各有理由 |
| 取得标准偏泛 | 09 第 3 节、底稿 EVID 表 | 每项有支持判断、最少内容、替代限度、缺失影响；按七类证据用途给具体底线 |

## 验证方法与范围

- [设备维修完整示范](../../../examples/设备维修-访谈准备与交接示范.md)：作者依据已公开 R1–R5 填写来源、认识、三个缺口取得标准、问题先问／复用／延期和条件追问；仅选一个主问题。另编答复单独标明，用来展示候选、取舍建议、草稿条目和未来指标待办的状态差异。
- 内容自查覆盖 QC01–QC10；每项指向实际示范位置及理由。规则正确的正例允许继续，避免一律待核；重复问已知、诱导回答、个人说法升级、索要模拟原件、读不全算全量、待审算正式口径等列为负例。
- 这是同一作者的文档演练及自查；未调用独立新 AI，不是盲测，不是客户效果或模型采用证明。用户的实际反馈是改进依据，不能改写成新版已经通过真实使用验收。
- 本轮未导出新的项目 PDF，也未重新宣称检查原 PDF；原母版不变。
