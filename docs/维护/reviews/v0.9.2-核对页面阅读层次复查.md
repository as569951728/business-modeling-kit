# v0.9.2 核对页面阅读层次复查

日期：2026-11-20。本地修改，未推送。

## 反馈与改动

使用者反馈首版没有重点、阅读疲劳，需要结构化呈现和清晰层次。本轮调整信息结构与样式，不接入真实项目或扩大执行范围。

- 顶部明确一个待确认点，元信息降为次要层。
- 访谈分为“找谁问 → 现场怎么问 → 至少带回三样”，首问与有条件追问分开；取证要求按案例、记录、依据分组。
- 关键未知保持可见；背景、详细影响、来源和答复回来后的处理按需展开。
- 模型／指标页使用“本次判断 → 结构化解释 → 留下意见”；例子、详细限制可展开，原来源和未知不删。
- 缩短默认文字、增加分组留白和字号层次，降低大面积白底亮度；窄屏先看当前节点，完整路线可展开。
- 原临时反馈、版本绑定、草稿下载与不自动推进约定保留。17 同步通用呈现规则，避免后续又把文档整段搬进页面。
