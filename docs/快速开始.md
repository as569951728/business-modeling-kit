# 第一次怎样使用

你只需提供工具包位置、客户资料或已有项目位置，以及这次想做的事。AI 负责读方法、整理材料、维护进度，你负责核关键判断。无需先分类资料、学习状态名或填完模板。

## 三步开工

1. **让 AI 读入口。** 指向本包 [AGENTS.md](../AGENTS.md)，已有项目同时读取项目登记和 AI 接续记录。
2. **说清本轮任务。** 可先整理材料／准备访谈、处理录音或文字访谈、生成方案、建立模型，或继续已有工作；已有信息不重复询问。
3. **先看进度简报。** AI 告诉你当前节点、已完成、尚缺和流程下一步。有争议时先解释，再给处理方案，支持选择和自由回复。

可直接告诉 AI：

> 请先读取【工具包位置】的 AGENTS.md，再读【客户项目或材料位置】。本轮要做【任务】。根据已有材料继续，缺口据实保留；先给进度简报，需要我判断时提供具体处理建议。成果放客户项目，保留原件和已有决定。

音频需执行环境有实际读取或转写能力；本包没有语音识别引擎。业务定义缺依据时保持待核，AI 可以继续不受缺口影响的工作。模板和虚构例只教方法，不是客户事实。

## 可选的本地辅助

以下由 AI 在**工具包根目录**运行，客户项目放在包外。无需安装第三方依赖。

```bash
python3 kit.py init '../客户项目' --task '先整理已有材料' --scope S1
python3 kit.py status '../客户项目'
python3 kit.py check --project '../客户项目'
```

默认只准备方案，已明确只盘点材料可用 `--scope S1`；本轮范围始终依据用户任务。状态更新、范围变更及只读查看的方法集中在 [11](项目协作/11-工作进度与接续.md)。重复初始化会保留已有工作；用户不必手写配置。
