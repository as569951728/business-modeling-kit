# 成果模板

模板由 AI 根据实际材料填写；已有同等记录直接复用，不要求用户全部填一遍。客户产物存客户项目，不存工具包。

指标库默认只设一个进度入口，再按需要形成定义和测试记录，不一次复制全目录。模板里的方法链接相对本工具包有效；AI 实例化到客户目录时须改成已登记工具包位置对应的实际链接，并核对材料／成果引用；没有产物就写未形成。指标入口的具体组织见 [13](../docs/指标库/13-指标库建立手册.md)。

| 说明项目和实施安排 | [项目背景](项目背景.md)、[实施方案](实施方案.md) |
| 盘点资料、准备现场访谈 | [资料盘点](资料盘点.md)、[访谈准备](访谈准备.md) |
| 整理访谈并准备处理建议 | [沟通记录提炼](沟通记录提炼.md)、[候选处理单](候选处理单.md) |
